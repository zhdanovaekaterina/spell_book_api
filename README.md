# spell_book_api

**spell_book_api** - API-сервис для управления заклинаниями персонажей в Dungeons & Dragons 5-й редакции (D&D 5e). D&D - настольная ролевая игра, в которой участники совместно рассказывают приключение, управляя персонажами в фэнтезийном мире. Кастующие классы - классы персонажей, чьи игровые способности включают использование магии: они изучают и/или подготавливают заклинания и расходуют ячейки заклинаний.

Сервис предоставляет справочную информацию о заклинаниях и ячейках, а также операции с персонажами-кастерами: учёт заклинаний, их изучение и подготовка, повышение уровня.

## Технологии

- **Python 3.11**
- **FastAPI** + **Pydantic 2**
- **PostgreSQL 12** + **SQLAlchemy 2** + **psycopg2** + **Alembic**
- **Dependency Injector**
- **Docker Compose**
- **pytest**

## API

Интерактивная документация OpenAPI доступна после запуска приложения по адресу `/system/docs`; Swagger UI — `/system/docs_old`, JSON-схема — `/system/docs/openapi.json`.

### Справочная информация

| Метод | Маршрут | Описание |
|---|---|---|
| `GET` | `/info/spells/available` | Доступные заклинания для класса и подкласса на указанном уровне. |
| `GET` | `/info/cells` | Доступные ячейки заклинаний для класса на указанном уровне. |

### Персонажи-кастеры

| Метод | Маршрут | Описание |
|---|---|---|
| `POST` | `/caster/create` | Создать персонажа первого уровня. |
| `GET` | `/caster/{id}` | Получить персонажа по идентификатору. |
| `DELETE` | `/caster/{id}` | Удалить персонажа по идентификатору. |
| `GET` | `/caster/{id}/spells/available` | Получить доступные персонажу заклинания с отметками изученных или подготовленных. |
| `GET` | `/caster/{id}/cells` | Получить доступные персонажу ячейки заклинаний. |

### Операции с заклинаниями персонажа в разработке

Следующие маршруты объявлены, но пока возвращают статус `501 Not Implemented`:

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/caster/{id}/spells/learn` | Получить заклинания, доступные для изучения. |
| `POST` | `/caster/{id}/spells/learn` | Зафиксировать изучение заклинаний персонажем. |
| `GET` | `/caster/{id}/spells/prepare` | Получить заклинания, доступные для подготовки. |
| `POST` | `/caster/{id}/spells/prepare` | Зафиксировать подготовку заклинаний персонажем. |
| `GET` | `/caster/{id}/spells/use` | Получить заклинания, доступные для использования. |
| `GET` | `/caster/{id}/spells/count` | Получить общее и оставшееся количество доступных для изучения или подготовки заклинаний. |

## Развёртывание проекта

1. Клонируйте репозиторий:

   ```shell
   git clone git@github.com:zhdanovaekaterina/spell_book_api.git
   ```

2. Создайте файлы конфигурации и заполните параметры подключения к базе данных и локального пользователя:

   ```shell
   cp .config/.env.example .config/.env
   nano .config/.env
   cp .config/.env.test.example .config/.env.test
   nano .config/.env.test
   ```

3. Соберите и запустите контейнеры:

   ```shell
   docker compose up --build -d
   ```

4. Примените миграции:

   ```shell
   docker compose --env-file .config/.env run app alembic upgrade head
   ```

5. Установите Git-хуки:

   ```shell
   cp -r .config/git-hooks/. .git/hooks/
   chmod -R 755 .git/hooks/
   ```

### Тестирование

Тесты запускаются в отдельном контейнере `test-app`, который использует код и тесты с хоста.

Соберите контейнер:

```shell
docker compose build test-app
```

Запустите тесты:

```shell
docker compose run --rm test-app
```

Для локального запуска установите зависимости из `.docker/local-requirements.txt`, затем выполните:

```shell
pytest --cov=app
```

Тесты также запускаются при коммите; если они завершаются с ошибкой, коммит не будет создан.

### Миграции

Создайте миграцию через контейнер `app`:

```shell
docker compose --env-file .config/.env run app alembic revision --autogenerate -m 'migration_name'
```

Добавьте созданный файл в Git:

```shell
git add app/repository/db/migrations/versions
```
